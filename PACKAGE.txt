EngineAI Studio Pro (engineAI-studio-pro)
=========================================

Linux + NVIDIA CUDA package for Kimodo motion demo and EngineAI T800 retargeting.

Included:
  - kimodo-metal-mps-support-main/  (Kimodo fork: NF4/matbee, CUDA)
  - web-version/gmr/                (T800 retargeting; t800 assets in git)
  - docs/                           (install, GPU, GitHub)
  - install_system_deps.sh, install.sh, run_*.sh

Not in git (download on target machine):
  - models/kimodo-llm2vec-nf4/       → ./download_nf4.sh
  - cache/huggingface/hub/          → ./scripts/download_kimodo_models.sh
  - web-version/gmr/assets/body_models/  → SMPL-X license (user download)
  - conda env kimodo-cuda            → ./install.sh

Transfer to server:
  rsync -avz engineAI-studio-pro/ user@gpu-host:~/engineAI-studio-pro/ \
    --exclude cache --exclude models --exclude vendor
